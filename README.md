# 青龙面板 京东Cookie 助手 安卓版

> 作者：Eyzer · 项目地址：https://github.com/Eyzer/jdck-android
>
> 在手机上获取、续期京东 CK，并自动推送到青龙面板。Cookie 到期后无需手动打开 App，后台会自己完成运营商本机号码认证登录、更新青龙环境变量。

## 下载安装

* 最新安装包（手机点开即可下载）：https://github.com/Eyzer/jdck-android/releases/latest/download/app-debug.apk
* 所有版本：https://github.com/Eyzer/jdck-android/releases
* 每次推送 `master` 后由 GitHub Actions 自动构建并发布，无需本地编译

## 功能

* **后台静默自动登录**：定时检测 CK，失效后在隐藏悬浮窗里自动走运营商本机号码一键登录，不弹界面
* **自动推送青龙**：登录成功自动写入青龙环境变量，按 `pt_key` 去重；青龙 token 过期自动重新登录
* **运行日志**：右上角菜单 → 运行日志，可查看、复制、清空，失败原因一目了然
* 保存/删除手机号，一键填号并勾选协议
* 一键复制 cookie、清空 cookie 并重新加载
* 青龙面板登录及更新 cookie，支持 ClientID / ClientSecret
* 短信验证码自动识别

## 使用步骤

1. 安装后打开 App，右上角菜单 → 青龙面板，填写面板地址与 ClientID / ClientSecret 并登录
2. 添加手机号，在底部下拉框选中要自动登录的账号
3. 菜单 → 开启后台自动登录（每 3 小时检测 CK）
4. 首次开启时按提示允许**悬浮窗**权限；国产 ROM 还需在系统设置里允许**自启动**、关闭**电池优化**
5. 保持移动数据可用。WiFi 下运营商网关取不到号码，可以正常检测 CK，但无法自动一键登录

账号密码登录说明：需要先手动切到账号密码登录页，账号密码用空格分隔，示例 `18888888888 123456`，有密码会自动点击登录。

## 运行日志与排障

菜单 → 运行日志，会记录每次检测与登录的关键步骤：

* 启动时的环境：网络类型（WIFI / CELLULAR）、悬浮窗权限、通知权限、是否忽略电池优化、账号、检测间隔
* Cookie 读取与校验结果（pt_key 已脱敏，只显示前 6 位与长度）
* 页面加载 URL、京东页面状态、是否触发一键登录、是否填号
* WebView 加载错误、JS 控制台输出
* 青龙推送每一步（读取环境变量、重新登录、新建或更新、启用）及失败堆栈

偶发失败时先看日志里对应时间点，常见原因：

| 日志现象 | 原因与处理 |
| --- | --- |
| `网络=WIFI` | 未走移动数据，运营商取不到号码；关闭 WiFi 或开启移动数据 |
| `缺少悬浮窗权限` | 去系统设置给 App 悬浮窗权限 |
| `自动登录失败 ... 已触发一键登录=false` | 京东未下发号码认证入口，多为非蜂窝网络或京东风控 |
| `京东要求安全验证` | 需要手动打开 App 完成滑块/短信验证 |
| `推送青龙失败` | 检查青龙面板地址、网络、ClientID/ClientSecret |

日志文件同时保存在 `Android/data/cn.xanderye.android.jdck/files/log/auto_login.log`，超过 256KB 自动轮转，只保留一份备份。

## 后台自动登录实现说明

* 检测跑在前台服务里，失效后在 1% 透明度的悬浮窗里加载京东登录页，不拉起界面，绕开 Android 10+ 的后台启动限制
* 页面渲染后自动勾选协议、点击"本机号码登录"、补全四位掩码格
* 定时用 AlarmManager 精确闹钟唤醒，服务被系统清理、手机重启后自动恢复
* 用户正在使用 App 时不会抢登录页，退到后台 30 秒后再自动登录
* 失败才发通知，点通知直接进 App 手动处理

## 自检

```
node tools/selfcheck-onekey.js
```

直接读取 `JsUtil` 里的注入脚本，用假 DOM 校验勾选协议、点击登录、补全掩码格、普通登录页不误点四种场景。

## 已知限制

* 运营商取号必须走蜂窝网络，WiFi 下不会出现号码认证入口
* 京东是否下发号码认证入口由京东决定，App 无法强制
* 若京东弹出滑块或短信验证，自动流程会停下并发通知，App 无法绕过
* 前台服务需要常驻通知，部分 ROM 会在通知栏显示"京东CK自动维护中"
