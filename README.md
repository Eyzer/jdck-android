# 青龙面板 京东cookie 助手 安卓版

## PC版
[JD_Get](https://github.com/yclown/ql_jd_cookie)

## 说明
v2
青龙面板 获取京东cookie使用 

原项目 地址(https://github.com/XanderYe/jdck-android) 项目作者没有更新，就接过来自己更了

## 优化
* 修改青龙面板的对应的接口地址
* 使用ClientID和ClientSecret进行接口对接
* 自动启用发送过去的脚本

## 功能
* 保存/删除手机号
* 一键输入手机号并打勾协议
* 一键复制cookie
* 清空cookie并重新加载
* 支持青龙面板登录及更新cookie
* 支持短信验证码自动识别

### 账号密码输入说明
* 需要先手动切换到账号密码登录页
* 账号密码使用空格分开 示例 18888888888 123456
* 有密码的会自动点击登录按钮

## 本分支新增（v2.4.0）

### 运营商本机号码一键登录
* 移动数据网络下，京东登录页出现"本机号码认证"时，自动勾选协议并点击一键登录，全程免密码
* 号码由运营商网关下发，App 不读取、不破解、不接管
* 页面上的四位打码格若实现为输入框，用账号列表里选中号码的第 4~7 位自动补全
* 浏览器标识去掉 wv，避免被京东判定为内嵌浏览器而收不到号码认证入口
* 操作入口：底部"一键登录"按钮可手动触发，页面加载后也会自动执行

### 手机号自动补全
* 登录页加载后自动把账号下拉框里选中的号码填进输入框，不需要再点"输入"
* 账号行带密码时，同时填入密码并点击登录

### 定时检测 + 自动上传
* 右上角菜单 → 开启定时检测CK（每 3 小时），用 WorkManager 检测京东登录态
* 失效后自动拉起 App 重新加载登录；系统拦截后台弹窗时改为发通知，点通知同样触发
* 登录成功拿到新的 pt_key 后自动写入青龙环境变量，同一 pt_key 只上传一次，不用再点"获取CK"
* 失效判定基于京东用户信息接口，网络异常一律按有效处理，宁可漏报不误触发重新登录

### 安装包
[dist/jdck-2.4.0.apk](dist/jdck-2.4.0.apk)

### 自检
```
node tools/selfcheck-onekey.js
```
直接读取 MainActivity 里的注入脚本，用假 DOM 校验勾选协议、点击登录、补全掩码格、普通登录页不误点四种场景。

### 已知限制
* 运营商取号必须走蜂窝网络，WiFi 下不会出现号码认证入口
* 京东是否下发号码认证入口由京东决定，App 无法强制，只能提高概率
* 安卓 10 起禁止后台随意拉起界面，被拦时依赖通知，需要手动点一下
* 国产 ROM（MIUI/EMUI 等）需给 App 自启动权限并关闭电池优化，否则定时任务可能不执行
* 若京东弹出滑块或短信验证，自动流程会停下等人操作，App 无法绕过
