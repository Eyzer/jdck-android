# 青龙面板 京东cookie 助手 安卓版

## PC版
[JD_Get](https://github.com/yclown/ql_jd_cookie)

## 说明
v2
青龙面板 获取京东cookie使用 

原项目 地址(https://github.com/XanderYe/jdck-android) 项目作者没有更新，就接过来自己更了

## 优化
* 修改青龙面板的对应的接口地址
* 使用ClientID和ClientSecret进行接口对接
* 自动启用发送过去的脚本

## 功能
* 保存/删除手机号
* 一键输入手机号并打勾协议
* 一键复制cookie
* 清空cookie并重新加载
* 支持青龙面板登录及更新cookie
* 支持短信验证码自动识别

### 账号密码输入说明
* 需要先手动切换到账号密码登录页
* 账号密码使用空格分开 示例 18888888888 123456
* 有密码的会自动点击登录按钮

## 本分支新增（v2.5.0 后台自动登录）

v2.4.0 的"定时检测"是在 WorkManager 里 `startActivity` 拉起 App，安卓 10 起后台禁止拉起界面，所以最后还是得手动点通知。v2.5.0 改成不需要界面的后台流程：

### 后台静默自动登录
* 右上角菜单 → 开启后台自动登录（每 3 小时检测CK）
* 检测在**前台服务**里跑，失效后在一个 1 像素的透明悬浮窗里加载京东登录页，不弹任何界面
* 页面渲染出来后自动勾选协议、点击"本机号码登录"、补全四位掩码格，全程走运营商本机号码认证
* 拿到新的 pt_key 后自动写入青龙环境变量（按 pt_key 去重），并把新 CK 存回 WebView 供下次检测
* 青龙 token 过期时自动用 client_id/client_secret 重新换取 token，不需要重新进设置页
* 定时用 AlarmManager 精确闹钟唤醒，服务被系统清掉、手机重启后都会自动恢复
* 失败才发通知：京东风控验证、超时、青龙推送失败，点通知直接进 App 手动处理
* 用户正在使用 App 时会跳过自动登录，避免和手动操作打架

### 需要给的权限
* 悬浮窗（必须）：菜单开启时会引导跳转授权
* 自启动 / 后台运行（国产 ROM 必须）：MIUI、EMUI、ColorOS 等要在系统设置里允许自启动并关闭电池优化
* 移动数据保持开启，且**优先走蜂窝**：WiFi 连着时运营商网关取不到号码，App 会尽量把进程网络绑到移动数据，但成功率不保证

### 安装包
* 云端构建：推送到 `master` 分支后 GitHub Actions 自动出包，在 Actions 页面下载 `jdck-debug` 制品
* 历史版本：[dist/jdck-2.4.0.apk](dist/jdck-2.4.0.apk)

### 自检
```
node tools/selfcheck-onekey.js
```
直接读取 JsUtil 里的注入脚本，用假 DOM 校验勾选协议、点击登录、补全掩码格、普通登录页不误点四种场景。

### 已知限制
* 运营商取号必须走蜂窝网络，WiFi 下不会出现号码认证入口
* 京东是否下发号码认证入口由京东决定，App 无法强制，只能提高概率
* 若京东弹出滑块或短信验证，自动流程会停下并发通知，App 无法绕过
* 前台服务需要常驻通知，部分 ROM 会在通知栏显示"京东CK自动维护中"
